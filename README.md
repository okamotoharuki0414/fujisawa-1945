# 線路のむこう、残った声

見慣れた駅と知らない一人のつながりを問い、現代から1945年へ突然転送される主人公の物語。「次へ」だけで暮らし、岩見高明氏の立場と三つの実回想、その後と帰還の意味を知れます。任意質問は本編を理解した後の補足で、章順や結末を変えません。

index.htmlは静的サーバーで配信、offline.htmlはブラウザーで直接開けます。読書位置は端末内だけに保存。出典と動画には通信が必要。file://動画が制限される場合は公式リンクを使用。

資料はmaterials.html、出典とメディア条件はsources.html、固定脚本はscenario.html、作品解説はmaterials/explanation.pdf。タイムスリップと概念画は演出。証言は後年の回想の原文引用。写真Nesnad/CC BY4.0のクレジットとリンクを保持。動画を再配布しません。
