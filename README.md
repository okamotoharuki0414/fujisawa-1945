# 線路のむこう、残った声 V5

架空案内人・灯の顔と手が見える対話、実写真8点、公式証言映像2本で、見慣れた駅と知らなかった一人のつながりをたどる固定の物語。次へだけで理解でき、映像/任意補足を飛ばしても同じ一つの帰還へ進みます。

index.htmlは静的サーバー、offline.htmlはブラウザーで直接起動。写真・人物・全本編を内蔵。外部の公式動画は通信と本人の操作が必要、音声OFFから開始。単独版は公式リンクを案内。

資料materials.html、全写真/映像の権利sources.html、全文scenario.html、解説materials/explanation.pdf。写真の年・作者・ライセンス・加工表示を保持。動画/音声/サムネイルを再配布しません。灯は実在証言者でなく、証言は後年の回想を原文引用。

一般公開。noindexはアクセス制限ではありません。
