# 藤沢1945 公開版

静的な歴史チャット教材です。index.htmlからゲーム、資料、ダウンロード案内へ進めます。依存ライブラリ、外部フォント、解析通信はありません。

通常版はこのフォルダの内容を静的ウェブサーバーで配信します。data.jsonは相対URLで読み込みます。単独のoffline.htmlは保存してブラウザーで直接開けます。内蔵データを優先し、教材読み込みの通信は行いません。外部出典へのリンクには接続が必要です。

検索エンジン向けのnoindex,nofollowは非公開措置ではありません。URLを知る人は閲覧・保存できます。

作品解説PDFはmaterials/explanation.pdf、オフライン配布ZIPはfujisawa1945-public.zipです。

シナリオと出典リストは公開用派生版です。証言の直接引用、出典URL、資料の範囲と利用条件を維持しています。実在証言者の氏名は出典表示として掲載し、写真・動画は転載していません。許諾不明の資料を自由利用可能とは扱いません。
