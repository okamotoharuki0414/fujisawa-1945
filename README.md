# 線路のむこう、記憶の余白

四地点を探索し八枚の手がかりから三枚以上を集め、三種類の読み方でノートを結ぶ静的ゲーム。

index.htmlは静的サーバーで、offline.htmlは保存後のブラウザー直接起動で動きます。ノートは端末内だけに保存。外部資料と公式YouTube動画には通信が必要です。

素材の出典・ライセンスはsources.html、作品解説はmaterials/explanation.pdf、シナリオはscenario.html。イラストは創作概念図で1945年復元ではありません。写真Nesnad/CC BY 4.0の表示と元ページ・ライセンスリンクを保持してください。動画は再配布していません。

noindexはアクセス制限ではありません。一般公開作品です。
